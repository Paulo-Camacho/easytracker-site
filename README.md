# Easy Tracker — Website

Public support, privacy, and terms pages for the Easy Tracker iOS app, used for the App Store listing.

**Live site:** https://paulo-camacho.github.io/easytracker-site/

## Pages

| Page | File | URL |

## Editing

The site is plain HTML served by GitHub Pages from the `docs/` folder. Edit a file, commit, and push to `main` — the site updates in a minute or two.
